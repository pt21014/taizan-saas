# taizan-saas 任务分解

> 依据 `docs/框架设计蓝图.md`。共 5 阶段 35 个任务，每个任务粒度为「一个 agent 一次会话 1–3 小时」。
> **模型建议**：Opus 用于安全敏感、设计敏感、需要在多处保持不变量一致的任务；Sonnet 用于搬运、样板、UI、脚本。
> **并行标记**：`并行` = 同阶段内无文件冲突，可同时开工；`串行` = 必须等依赖完成。
> 所有任务的通用完成条件：`pnpm lint && pnpm -F <包名> test` 全绿，prettier 无分号单引号，新增公开 API 有 TSDoc。
